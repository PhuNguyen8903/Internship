## 📃 Kiến thức học được

###  week-4 bài 6
* Kubernetes autoscaling
* Horizontal Pod Autoscaler: scale số lượng replica trong deployment, sử dụng 2 metrics : CPU Utilization, custom và external metrics
* cluster autoscaling: tự động scale những node mới để có thể deploy thêm những node để chứa các pods
* karpenter : giúp scale cụm cluster hiệu quả hơn 

* cách cluster scale up :
- liên tục tìm unschedulable pods mỗi 10s
- add vào các pods có sẵn còn dư chỗ
- CA tạo ra một node mới nhằm schedulable pod chưa nằm trong node
* cách cluster scale down:
- liên tục quét các node ko cần thiết mỗi 10p
- chọn ra pods nào move được chọn node đấy 
- evict các pods bên trong và taint node đấy 
- rescheduler evicted pods và node đấy sẽ bị terminated
* challange khi sử dụng cluster autoscaling
- phụ thuộc vào auto scaling group => ko flexible
- ko thực sự tối ưu

* cách karpenter hoạt động : 
- check các pending pods và kiểm tra resourch của EC2 có đủ ko 
- nếu ko đủ => unschedulable pods
- gọi thẳng API của EC2 và cấp phát EC2 instance trực tiếp vào cluster

* karpenter scale up 
- cấu hình HPA để scale pods cho tới khi bị pending pods
- gọi karpenter cấp phát instance type phù hợp với request
- ép thêm node mới nếu cần

* karpenter scale down
- check ra empty nodes 
- cấu hình thông số TTL
- xóa empty nodes
