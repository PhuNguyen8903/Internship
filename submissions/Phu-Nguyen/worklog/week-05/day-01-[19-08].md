## 📃 Kiến thức học được

###  week-5 : Integrate ECS with the other AWS service

* * Deep integration with the AWS services
- load balancing : Classic ELD , ALB, NLB.
- Developer tool : AWS codestar, AWS cloud9, AWS CodePipeline, AWS X-ray
- networking : S3, Cloudfront , NAT gateway, App mesh , Cloudmap
- storage : Redshift, RDS, EFS, DynamoDB, Elasti Cache
- security : AWS IAM, Cognito, Secret Manager 
- Management and govermence : CloudWatch ,CloudFormation , CloudTrail, Systems manager

* ECS container image registry
- là dịch vụ quản lý kho chứa (registry) hình ảnh container do AWS cung cấp. Nó giúp lưu trữ, quản lý, và triển khai các container images (như Docker images) một cách an toàn, đáng tin cậy và dễ mở rộng.
- ECR là dịch vụ được AWS quản lý hoàn toàn, đảm bảo tính bảo mật, mở rộng và tin cậy khi lưu trữ container images
- Lifecycle policies for container images
- Tích hợp với AWS IAM để kiểm soát quyền truy cập vào registry và repository
- Hỗ trợ quét bảo mật images để phát hiện lỗ hổng phần mềm (security vulnerabilities) bên trong images
- ECR hỗ trợ cả repository riêng (private) và repository công khai (public). AWS còn có ECR Public Gallery – nơi chia sẻ images công khai giống như Docker Hub.
- Pull through cache
- Cross region and cross account replication : Hỗ trợ sao chép images qua nhiều vùng (region) và tài khoản AWS khác nhau

* ECS deployment
- tích hợp sâu với AWS codeDeploy
- CodePipeline dùng quản lý toàn bộ quá trình CI/CD
- quy trình : User => AWS CodeCommit => AWS Codebuild => AWS CodedDeploy => AWS Elastic Container Service

* ECS Observability 
- bao gồm 3 thành phần : logs , metrics, traces
- 3 công cụ này sẽ có các công cụ để xử lý 
- metrics-Amazon CloudWatch Container Insights
- logs-Amazon ECS Firelens for logs
- traces-AWS X-ray
