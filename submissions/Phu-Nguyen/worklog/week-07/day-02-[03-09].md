## 📃 Kiến thức học được
###  week-7 : AWS Application migration service(AWS MGN)
- Re-host VM hoặc máy chủ vật lý lên AWS dưới dạng EC2
- thường nằm trong mobilize phase và migra phase

* AWS MGN : a lift-and-shift solution
- hỗ trợ lift and shift từ VM từ bất cứ môi trường nào lên trên aws
- linh hoạt, tự động hóa
- giúp migra ứng dụng tốt và tiết kiệm nhiều thời gian
* 2 phases của application modernization
- phases one : lift-and-shift
- phases two : Modernize
* how AWS MGN works 
- cần cài agent tại máy chủ phía on frame
- agent sẽ tạo một server Replication tùy thuộc vào số lượng disks trong môi trường source
- Replication start volumes kết nối vào server replicate tùy thuộc vào disks trong mt source
- khi cutover từ on frame sang AWS thì sẽ tạo Cutover EC2
- cutover convert theo source
- sau khi Cutover xong có thể xuất DNS sang cutover để user có thể chuyển sang

* hỗ trợ rất nhiều platform
* Disaster recovery options: before or after migration
- có thể cái plugin để sử dụng DR khi thực hiện migrate
