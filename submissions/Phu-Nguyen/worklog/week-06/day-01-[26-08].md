## 📃 Kiến thức học được
###  week-6 : Cost Considerations for EKS
* Karpenter : một open source , flexible  và high performance
- là công cụ thay thế cho cluster scaler
- dựa vòng defination của pods để hiệu chỉnh cho hợp lý

* Containers + Spot
- mix ondemand và spot instance
- đảm bảo đủ khối lượng spot instance

* EC2 Spot instance pools
- cần mix nhiều dòng máy 
- chọn nhiều spot instance khác nhau cho pools

* Spot Instance Pricing History Dashboard
* EKS spot Utilization
- discount 50-70$
- sử dụng karpenter để đơn giản hóa sử dụng spot instance
- spot có thể bị terminate bất cứ lúc nào
- nên cài node termination handler

* AWS Node termination Handler
- có 2 cơ chế hoạt động : instance meta data service (IMDS) và Queue processor 
- IMDS chạy bên trong node => chạy dưới dạng daemonset mỗi node đều có một agent
- Queue chạy dưới dạng deployment
- queue cần cấu hình 

* Handling Spot Interruptions with EKS
- tìm ra spot instance bị reclaimed
- có 2p để làm tác vụ : Cordon , drain , Replace

* EKS monitoring
- bao gồm 3 plugins : Kube-Resource-report,Kube-cost,kube-downscaler
- kube-resource-report : là công cụ hỗ trợ làm rigts-sizing
- Kube-cost : công cụ giám sát chi phí theo nhiều chiều khác nhau
- kube-downscaler : cho phép đặt lịch và scale worklogs xuống tới mức nào đó
