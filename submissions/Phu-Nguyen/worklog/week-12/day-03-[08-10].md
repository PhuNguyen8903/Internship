###  week-12 : Data Transformation
* AWS glue Job Bookmarks
- book mark lại các dữ liệu đã xử lý và xử lý tiếp các dữ liệu chưa xử lý
- nếu nguồn dữ liệu là các dữ liệu có quan hệ thì dùng key thì glue sẽ book mark theo key đó 
- nếu nguồn là S3 thì book mark sẽ check ngày gần nhất dữ liệu thay đổi để xử lý lại các dữ liệu mới hoặc sửa đổi
* AWS Glue : python shell job
- chỉ cần viết python để thực hiện xử lý dữ liệu 
- phù hợp xử lý job nhỏ, đơn giản
- thời gian thực hiện job nhanh
* AWS Glue streaming ETL
- hỗ trợ xử lý dữ liệu streaming
- nguồn : Amazon kinesis, Apache kafka,Amazon managed streaming
* AWS glue workflow
- để xây dụng pipline thực hiện mỗi lần trigger
- 3 thành phần : crawler,jobs, trigger
* AWS Glue integrated scheduling và provisioning
- có một glue job manager sub job vào cluster
- cluster sẽ phân tán job cho các worker trong worker node
- cluster chạy task sao cho dữ liệu song song với nhau
- nếu job manager thấy ko đủ instance, GPUs thì spark tự động tăng số lượng instance trong cluster
- nếu instance có sẵn sẽ nằm trong warm pool
- nếu dư tài nguyên glue sẽ xóa bớt để đảm bảo tối ưu
* Glue execution model
- chạy trên cơ chế song song
- dữ liệu sẽ được đẩy vào từng partition 
- job được chia theo stage
- data chia theo partition
- 1 stage + 1 partition = 1 task
* Glue brew
- dành cho data scientist, data analysts
- no code, ko cần viết script
- hiểu được quality dữ liệu
- hoàn toàn serverless
