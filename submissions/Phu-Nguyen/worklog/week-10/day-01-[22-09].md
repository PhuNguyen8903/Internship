## 📃 Kiến thức học được
###  week-10 : API Gateway
- là cổng để bảo vệ backend giúp expose function
- có thể đứng phía trước public và private service
* Amazon API Gateway là full serverless : dễ dàng dev API và public,..

* Support Protocols
- hỗ trợ 2 nhóm : REST API, WebSocketAPIs
- REST API : dạng request/response
  thích hợp communication ngắn
  stateless
- WebSocketAPIs : kết nối hai chiều và lâu 
* RESTful APIs
- 2 loại : REST API, HTTP API
- REST : Có nhiều feature hơn hỗ trợ nhiều
- HTTP : Đơn giản hơn , chạy nhanh hơn 60% so với REST, chi phí rẻ hơn 70%
* Endpoint types
- REST có thể deploy Edge location, có thể deploy private
- HTTP chỉ có thể deploy theo region
* API Gateway interaction và patterns
* protech API Gateway
- hỗ trợ nhiều cơ chế bảo vệ khác nhau
- firewall cho HTTP
- hoàn toàn có thể config với cognito user pools và sẽ chiếm thêm một ít times
* Resource Policies : REST API
- cho phép account theo policies
* Web Application Firewall : REST API
- định nghĩa Rule và apply theo rule
* xác thực JWT/Cognito
- hỗ trợ đa dạng hơn 
- config denine hoặc accept theo token
* Throttling và usage plans 
- có thể config usage plans cho nhiều client khác nhau
- cần sử dụng throttling để bảo vệ hệ thống
* 4 levels của Throtting
- REST : throt theo từng clients và method
* Usage plans và API Keys
- cung cấp API Keys cho clients
- có thể xác định ai có thể access API
* stages 
- API Gateway cho phép định nghĩa stage để giải quyết nhiều bài toán
- cho phép versioning API và rolled back 
* Canary Releases
* caching
- có thể caching một số tính năng
- có thể config khép trên API
