## 📃 Kiến thức học được
###  week-13 : Data Warehouse
* Analyze data
* reference architecture
- inject dữ liệu vào S3 
- sử dụng công cụ ETL
- tranform dữ liệu 
- query dữ liệu tranform qua access layer
* BI và query
- khi đã có dữ liệu tranform load vào red shift, Athena có thể dùng làm nguồn dữ liệu làm báo cáo BI
* Amazon Redshift
- data warehouse service dưới dạng pully managed 
- cơ bản ko cần quan tâm hạ tầng 
- độ sẵn sàng rất cao 
- bảo mật tốt
- scale tới Gbs,EBs 
- khi dữ liệu tăng sẽ ko bị giảm tốc độ
- có tích hợp với các service khác của aws 
* technical Redshift
- là dạng engine customize để phục vụ storage
- tích hợp trực tiếp với datalake trên S3 để build service dưới dạng managed
* Redshift cluster architecture
- redshift leader node : là endpoint để truy cập
- compute nodes : dữ liệu sẽ được lưu trữ trên đây
- spectrum nodes : để tăng tốc, query trực tiếp vào S3
* RA3 node with managed storage
- tách compute và lưu trữ storage trên customize storage dành riêng cho redshift
* Redshift instance types 
- Amazon Redshift RA3 : managed storage , share storage giữa tất cả các nodes
- Dense compute- DC2 
* Redshift Cluster VPCs
- chạy trong VPCs nghĩa là dữ liệu rất bảo mật
* Cluster Relocation
- có thể relocate cluster từ AZ này sang AZ kia với redshift managed storage
- dữ liệu được lưu cross zone khi relocate 
- cluster endpoint ko thay đổi khi đổi AZ
* Enhanced VPC routing
- truy cập từ redshift qua các tool liên quan cho phép tất cả traffic giữa redshift cluster đi bên trong vpc
* Amazon Redshift federated Query
- từ redshift có thể query dữ liệu ko nằm bên trong mà nằm bên ngoài
* Redshift spectrum : seamless integration
- kết hợp với SQL, BI có thể write trực tiếp dữ liệu vào S3
* Amazon redshift : Data storage
- là một nơi lưu trữ dữ liệu dưới dạng cột và lưu trong blocks 1mb
- các cột sẽ được lưu vào các slide tương ứng 
* Redshift distribution styles
- có 4 kiểu lưu dữ liệu : Auto,key,all,even
* Amazon Redshift : operation
- tích hợp với cloudwatch cho tracking các metric cho redshift
- các dữ liệu về performance và tải sẽ được lưu trữ trong cloudwatch
* Automatic workload managenment
- là một cách phân chia priority giữa các query
- cho phép đảm bảo gán priority cho các node 
- sử dụng machine learning để tối ưu throughput
* Redshift cluster resizing : Elastic resize , classic resize
* Redshift Advisor
