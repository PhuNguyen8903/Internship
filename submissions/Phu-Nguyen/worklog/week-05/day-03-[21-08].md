## 📃 Kiến thức học được
###  week-6 : AWS Observability tools 
* cách phân loại observability
- log, metrics và tracing 
- ngoài ra còn có công cụ giám sát ở mức hạ tầng bao gồm các thông số về ram ,memory
- cao hơn có application monitoring là thông số về ứng dụng bao gồm hiệu năng, tỉ lệ lỗi 
- mới đây có thêm Synthetic monitoring là loại giả lập khối lượng người dùng thực tế để đẩy request vào hệ thống
* Công cụ cho phần tracing,metrics,log : AWS x-ray
- công cụ tracing với mục đích mô hình hóa dữ liệu những vấn đề liên quan hiệu năng và lỗi
- là một instrumentation cho phép colect white box metrics
* cách X-ray hỗ trợ
- phân tích và debug cho hệ thống phân tán khi có vấn đề xảy ra
- có thể hoạt động trong và ngoài AWS 
- cho phép sử dụng nhanh với độ trễ thấp
* X-ray Concepts 
- trace : là một request/responts đi vào hệ thống 
- trong trace có segments : là một đoạn xử lý của một request nằm giữa hai chỗ nhúng được sdk
- các chỗ ko nhúng được sdk mà xử lý phân mảnh thì tự động tạo ra sub-segments 
* X-ray SDK
- là một thư viện cần nhúng vào trong code để dùng x-ray
- support cho java,.net, .net core , Ruby, Python, Go và Node.js
- support một số dịch vụ aws và dịch vụ thứ 3 
* AWS X-ray for Amazon ECS/EKS
- để có những thông số lên aws cần một agent là EKS/ECS
- X-ray sdk nhúng vào microservice
- cần chạy X-ray agents 
- app trong cluster dùng sdk đọc thông tin
- gửi thông tin về X-ray agents
* Visualize service graph
- màu đỏ lỗi 500
- màu vàng lỗi từ client
* CloudWatch Container Insights
- là một tính năng cloudwatch dành riêng cho container
* Metrics in containerized Applications
- 2 loại : system metrics và service metrics
* CloudWatch Container Insights 
- cần một cloutwatch Agents
- chạy bên trong cụm EKS ECS
- collect instance-level metrics 
* CloudWatch Container Insights for Prometheus
- cần custom metrics ở mức application
- dùng prom sdk nhúng code để collect thông số 
* CloudWatch Logs cho ECS
- có 2 cách thu thập logs : awslogs driver và firelens Logs 
- firelens cho phép application gửi logs từ nhiều destination và làm việc với cả fluentD, fluentBit
- firelens đều có thể dùng trên EC2 và Fargate
* CloudWatch Logs cho EKS
- bao gồm 2 phần chính : logs của control plane và logs của application
- sử dụng FluentBit để gửi application logs ra ngoài destination
