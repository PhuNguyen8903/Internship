## 📃 Kiến thức học được

###  week-5 : ECS

* ECS control plane:
- ko có chi phí liên quan tới ECS
- ko cần upgrade ,patch,secure

* Task placement: là một tập các rule giúp tìm chính xác các cái worker node để scale
- cluster constraints
- custom contraints
- placement strategies
- apply filter

* ECS data plane
- thân thiện với người dùng
- các worker node đặt trong VPC và gom vào một autoscaling group

* ECS core constructs
- cluster
- service
- task
- compute

* Task là một instance đơn của một application trong ECS
- một task có nhiều container

* Service : là một replication của nhiều task hoặc chạy dưới dạng daemon và chạy dưới dạng load balancer
- có thể thực hiện autoscaling

* RunTask vs. Service : là hai cách thức chạy ECS application
- service sẽ chạy 24/7 
- runtask chạy tác vụ onetime

* ECS IAM role 
- instance profile
- service linked Role
- Task Role
- Task Execution Role
