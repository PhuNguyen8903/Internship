###  week-5 : Fargate

* Introducing Fargate: serverless compute engine dành cho container nghĩa là pack của nó vẫn là EC2 nhưng khách hàng ko cần quản lý 
* fargate at a glance : mức độ adoption của fargate khá đáng kể 
* benefits : 
- serverless
- secure by default 
- saving 
* AWS fargate data plane architecture:
- phần hiện diện VPC customer rất ít 
- các phần còn lại đều nắm bởi aws
* ECS fargate compute : sẽ provision resource dựa trên task vCPU và memory
- AWS cung cấp 1 cặp giá trị CPU và Memory
* Cách introduce vào task definition 
- Đặt phần longsty vào thì sẽ thành target mode
* AWS Fargate task networking:
- Yêu cầu awsvpc network mode
- Mỗi task có ENI riêng nó 
- Apply security groups mỗi task
- Task ENI có địa chỉ IP từ subnet
* ECS autoscaling :
- Auto scaling in/out số lượng task của 1 service
- Chỉ cần scale task ko cần quản lý EC2
- Khả năng scale in/out nhanh hơn khá nhiều
