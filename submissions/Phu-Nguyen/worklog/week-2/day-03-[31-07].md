## 📃 Kiến thức học được

###  week-2 bài 04
* AWS Database bao gồm :
- purpose-built databases:
- relational : aurora, RDS
- Key-values : Dynamo DB
- Document: Document DB
- In-Memory : ElastiCache , MemoryDB
- Graph : Neptune
- Time-series: Timestream
- Ledger :QLDB
* Aurora:là một loại database do aws tạo ra để mang lại performance cao hơn và đang hỗ trợ cho MySQL và PostgreSQL
* Serverless : bất kỳ serverless nào cũng có warm up time tuy nhiên khá nhỏ 
- Aurora serverless : ko manage phần cứng nào của server db chỉ tính tiền cho mỗi query db
- DynamoDB dành cho document database : cũng tương tự các db khác
- Global Table: khi lưu dữ liệu vào đây các replica sẽ liên kết các region với nhau
- DAX(dynamoDB accelerator) : tạo ra cash khi write, read dữ liệu hỗ trợ optimize dữ liệu
- DocumentDB : hỗ trợ Mongo DB 
- mức độ scale lớn ko quan tâm performance
- ElastiCache : mang đầy đủ điểm mạnh và tính chất cho fully manage aws
bản chất là managed Redis và memcached-compatible
- MemoryDB : Redis-compatible
- neptune : dùng trong trường hợp muốn một database lưu lại quan hệ của những đối tượng và có thể truy vấn quan hệ đấy(hay sử dụng cho mạng xã hội)
- time stream : lưu data dạng tại thời điểm này sẽ xảy ra gì đấy
- QLDB : dành riêng cho việc ghi lại các transaction ghi lại các giao dịch củ thể và ko được phép thay đổi
- apache cassandra(key space): là distributed database hỗ trợ wide collumn database 
Wide column: keyspaces
