## 📃 Kiến thức học được
###  week-12 : Data Ingestion
* seamless Data movement
- có 3 di chuyển trong data platform: inside out, outside in, around the perimeter
* Data source
- những dữ liệu có cấu trúc : bắt nguồn từ ERP application, CRM,CMS,SAAS,SAP application,SQL database
- Semi cấu trúc(bán cấu trúc) : Web application, NoSQL database ,JSON , CSV, XML,..
- ko cấu trúc : Video file , audio file, images, IoT data, ..
- batch : dữ liệu thay đổi trong thời gian nhất định 
* AWS Database Migration Service DMS:
- hỗ trợ liên tục replica dữ liệu 
- hỗ trợ chuyển dữ liệu tới redshift, s3 , cơ sở dữ liệu 
- replica từ dữ liệu tới data platform
- DMS hỗ trợ chuyển đổi database trong cùng 1 định dạng database
- hỗ trợ fan out
* AWS Lake Formation Blueprints
- được kết hợp với bluejob
- phương pháp thay thế của DMS : dùng để chuyển lưu dữ liệu vào S3
* steaming data source
- kinesis data stream : chuyển dữ liệu và access dữ liệu stream dưới 1s,dữ liệu được lưu 24h
- AWS kinesis fire hose : hỗ trợ gom dữ liệu tới nơi lưu trữ, là nơi buffer
- AWS kinesis Data analytics : thường dùng chung với data stream , có thể dùng truy vấn time window
- kinesis data stream : là serverless, tính sãn sàng cao, đặt ở multiAZ
* Amazon managed streaming for Apache kafka
- dùng theo cluster dùng để quản lý cluster, worker,worker node, zoo keeper
- AWS sẽ quản lý hộ zoo keeper và worker 
- tự đưa ra cấu hình
- latency thấp, nhanh 
- Odering : có topic,producer,consumer, dữ liệu tùy vào topic
- tính phí dựa trên instance đặt vào cluster
- tùy vào cấu hình trong instance mà có thể lưu trữ bao lâu
* Amazon Appflow 
- dùng để chuyển dữ liệu từ app SaaS 
- chỉ cần chọn ứng dụng và kết nối tới nơi chứa dữ liệu
- near realtime
