###  week-13 : Orchestration
Orchestration
* Apache Airflow
- là một orchestration 2 được xây dựng và xuất phát từ bài toán data analytics
* DAG- Directed acyclic graph
- là một graph, mỗi hình tròn là một task , mỗi cạnh phụ được đầu vào và ra của task khác 
- thực thi graphs từ trái sang phải, từ trên xuống đưới
- ko có khái niệm về loop
* apache air flow components
- scheduler 
- worker nodes
- web server
- data database
* Amazon managed workflow for apache airflow(MWAA)
- là một dịch vụ manage service cho apache airflow
- khách hàng ko cần set up quản lý nhiều
- hoạt động = cách tạo MWAA environment trên aws control 
- copy mô tả DAG và plugin vào s3 puckage
- access Airflow UI
* Use case
* cách tạo workflow trên airflow
- tạo task 
- chạy Query định nghĩa task
- định nghĩa relationship
- schedule 
* Movie Lens using CDK
* Workflow studio 
- thân thiện dễ sử dụng
* cách quản lý dependency
- nhiều hơn 1 upstream tasks
* complex dependencies
- airflow phù hợp hơn stepfunction
* stepfunction distributed map
- các dữ liệu sẽ được chia nhỏ và xử lý theo dạng batch
* Loop
- stepfunction intergrate loop rất tốt
- airflow ko thể config loop mà phải tạo task mà loop bên trong task
* chia sẻ data giữa các task và state
- đối với step function : có outputs inputs của parameters nhưng giới hạn dung lượng dữ liệu tối đa có thể truyền
- đối với airflow: có xcom một database tập trung để giải quyết bài toán truyền dữ liệu
* nhiều hơn một schedule cho một workflow
- stepfunction : có thể kích hoạt với event bridge
- airflow : schedule theo dag nên phải tạo nhiều DAG 
* monitoring 
- airflow có nhiều công cụ : giao diện, dashboard , managed airflow có tích hợp cloudwatch log, cloud trail
- stepfunction : tích hợp với cloudwatch log, cloudtrail , khi kích hoạt dịch vụ nào thì có service log tương ứng
* security boundaries
- airflow : sử dụng execution role config cho từng workflow cho truy cập vào aws service khác 
- có thể tạo environment riêng để enforce security boundary
- step funcion : sử dụng execution role, cấp quyền theo dạng service level
