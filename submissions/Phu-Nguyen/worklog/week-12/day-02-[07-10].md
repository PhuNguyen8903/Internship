- hỗ trợ xây dựng pipline xử lý dữ liệu

- glue hỗ trợ inject dữ liệu với glue connector
- glue Crawlers hỗ trợ khám phá dữ liệu qua schema

* unified data catalog 
- đứng giữa để hỗ trợ kết nối giữa data platform và công cụ phân tích
- luôn cần data catalog
- dùng crawler để hỗ trọ qua classifiers để tìm ra định dạng dữ liệu 
- qua đó lấy schema
